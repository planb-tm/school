# Скриншоты урока «Как оформить заказ»

Пошаговая инструкция использует 14 исходных изображений `order-wizard-01.png` - `order-wizard-14.png` в порядке шагов. Размер каждого файла - 941 × 1672 px.

При замене скриншотов сохраняйте их порядок, исходные пропорции и видимую маскировку персональных данных. Не редактируйте текст, цены, коды или интерфейс внутри изображений.

Названия шагов, пояснения и пути к изображениям находятся в `src/data/learning/orders.ts`.
