# Модель данных

## VerificationStatus

- `verified` - формулировка / цифры сверены со страницей источника
- `needs_review` - документ есть, но сверка не завершена
- `outdated` - источник устарел относительно текущей программы

## SourceDocument

Метаданные официального документа: название, версия, рынок, период, файл, статус, заметки.

## KnowledgeCard

Карточка знания:

- `plainExplanation` - простыми словами
- `officialWording` - близко к официальной формулировке
- `conditions` / `exceptions` / `examples` / `commonMistakes` - отдельно
- `sources` - ссылки на `SourceDocument` и страницы
- `status` - статус сверки

## CalculationExample

Контрольный пример: входы, шаги, ожидаемый результат, источники, дисклеймер.

## LearningQuestion

Вопрос теста: варианты, индекс правильного ответа, объяснение, источник.

## LearningProgress

Локальный прогресс модуля: выполненные задания, ответы теста, результаты сценариев.

## Правила источников

1. Не добавлять несуществующие официальные источники.
2. Если точная формулировка не извлечена - `needs_review`, без выдуманных условий.
3. Каждое правило и каждый контрольный расчёт должны иметь `sources`, если источник известен.
4. Цифры примеров - иллюстрации из документа, не гарантия дохода.
