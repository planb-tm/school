# Как обновить акции каталога

Админка, сервер и база данных не нужны. Компоненты интерфейса читают типизированные данные; обычное обновление затрагивает один файл каталога, его материалы и реестр.

## Где что хранится

| Файл или папка | Назначение |
| --- | --- |
| `src/data/learning/catalogs/types.ts` | Общий формат каталога, акций, слайдов и документов |
| `src/data/learning/catalogs/2026-15.ts` | Данные каталога №15 2026 года, пример заполнения |
| `src/data/learning/catalogs/index.ts` | Список каталогов и `currentCatalogId` |
| `public/media/catalog-offers/2026-15/` | Изображения презентации и официальный PDF этого каталога |
| `src/components/CurrentCatalogOffers.tsx` | Единый шаблон, обычно менять не требуется |

## 1. Соберите официальные материалы

Проверьте номер, год, период каталога, даты участия каждой акции, ограничения и срок получения по официальным документам Oriflame. Сохраните официальный PDF без исправлений. Изображения презентации сохраняйте без изменения содержания и пропорций; для страницы можно подготовить уменьшенные копии.

Не переносите автоматически условия прошлого каталога. Не приравнивайте окончание участия или выдачи приза к окончанию каталога. Если документ не даёт точной даты участия, укажите `null` в соответствующем поле и заполните `dateNote` проверенной формулировкой из источника. Такая акция не получит неподтверждённую отметку «Действует».

## 2. Создайте отдельную папку материалов

Создайте `public/media/catalog-offers/<год>-<номер>/`. Добавьте оригинальные изображения слайдов, их превью и PDF. Материалы прошлых каталогов оставьте в их папках.

В данных указывайте путь относительно `public/`, например `media/catalog-offers/2026-15/slide-02.webp`. Не добавляйте `public/`, `/school/` или начальный `/`: приложение само учитывает базовый адрес. Для PDF также допустима прямая HTTPS-ссылка на официальный документ. Не заменяйте официальный документ ссылкой на сторонний пересказ.

## 3. Добавьте файл данных

Скопируйте `src/data/learning/catalogs/2026-15.ts` в новый файл с идентификатором каталога. Сохраните проверку `satisfies Catalog` и замените содержимое по новым источникам:

- `id`, `number`, `year`, `startDate`, `endDate` - идентификатор, номер, год и период каталога.
- `verifiedAt` - дата фактической проверки материалов.
- `documents` - уникальный `id`, название, путь `href` к официальному PDF и необязательное описание редакции.
- `offers` - массив акций. Для каждой укажите уникальный `id`, аудиторию, заголовок, описание, собственные `startDate` и `endDate`, ссылки `sourceDocumentIds` на документы этого каталога.
- `image` - номер слайда, заголовок, доступное описание `alt`, пути `src` и `previewSrc`, ширину и высоту оригинала в пикселях.
- `facts`, `eligibility`, `steps`, `conditions` - основные показатели, участники, порядок действий, условия и ограничения.
- `receipt.description` - когда и как получить предложение; `receipt.deadline` заполняйте только при наличии подтверждённого крайнего срока.

Все даты записываются как `YYYY-MM-DD` и включают указанный день. Обе даты каталога обязательны. Даты участия акции могут быть `null` только с пояснением `dateNote`. Срок получения не наследуется из дат каталога и может быть позже них.

Дополнительные блоки `sections` необязательны:

- `schedule` - заголовок, подпись, строки календаря и пояснение. Все тексты строк хранятся в данных.
- `gallery` - заголовок, подпись и дополнительные оригинальные слайды.
- `items` - раскрывающийся список вариантов с названием, описанием, кодами и наименованиями.

Если новый каталог не использует такой блок, удалите его из данных. Не оставляйте старые призы, календарь или ограничения. Не добавляйте проверку номера каталога или `offer.id` в JSX.

## 4. Укажите текущий каталог

В `src/data/learning/catalogs/index.ts` импортируйте новый файл, добавьте его объект в `catalogRegistry.catalogs`, а в `catalogRegistry.currentCatalogId` укажите новый `id`.

Предыдущие объекты оставьте в списке: их данные и материалы хранятся отдельно. `getArchivedCatalogs()` возвращает все каталоги, кроме выбранного. Отдельная страница архива не создаётся.

Текущий каталог выбирается явно, а не по системной дате. Поэтому после окончания каталога приложение не переключится незаметно на старый. При `currentCatalogId: null` отображается сообщение, что материалы пока не опубликованы.

## 5. Проверьте данные и сборку

Из корня проекта выполните:

```sh
npm run validate:catalog
npm run typecheck
npm run test
npm run build
```

Проверка каталога проверяет обязательные поля, вложенные блоки, уникальность идентификаторов, реальные календарные даты, ссылки на документы, безопасные пути и наличие всех локальных изображений и PDF. Проверяются все записи реестра, включая прошлые каталоги. Эта проверка автоматически запускается и перед `npm run build`. Отсутствующий файл или некорректная запись должны быть исправлены до публикации. TypeScript дополнительно проверяет формат при редактировании.

Откройте `/learn/catalog-offers` на телефоне и компьютере в обеих темах. Проверьте изображения, увеличение слайдов, PDF, длинные названия, клавиатурный фокус и нижнюю навигацию.

## Как отображаются завершившиеся акции

Статус рассчитывается по датам конкретной акции, включая последний день участия. После него показывается «Участие завершено», а условия и документы остаются доступными. Срок получения отображается отдельно; после него появляется «Срок получения завершён». Дата окончания каталога не меняет даты его акций.

При завершённом выбранном каталоге появляется общее сообщение о завершении. Новый каталог не подставляется автоматически: его нужно проверить и выбрать в реестре.

Используйте в текстах обычный дефис `-`. Служебные пояснения о расхождениях в исходных документах не добавляйте на страницу акций.
