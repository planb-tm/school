# Архитектура planB

Простое SPA без backend. Бренд интерфейса - **planB** (команда внутри Oriflame).  
Один человек должен спокойно развивать проект через Cursor.

## Слои

| Папка | Назначение |
| --- | --- |
| `src/app` | Маршруты и стартовые экраны |
| `src/components` | Общие UI-компоненты |
| `src/data` | Источники, карточки, примеры, тесты - отдельно от React |
| `src/features` | Самостоятельные модули обучения |
| `src/lib` | Чистые функции: расчёты, прогресс, форматирование |
| `src/types` | Общие TypeScript-типы |
| `src/tests` | Автотесты расчётов |
| `docs` | Описание модели и правил работы с источниками |
| `docs/sources` | Официальные PDF |

## Принципы

1. Данные не живут внутри JSX.
2. Расчёты - чистые функции в `src/lib`, покрытые тестами.
3. Официальный текст, учебное объяснение и иллюстративный пример не смешиваются в одном поле.
4. Нет абстракций «на вырост»: новый модуль = `data/<module>` + `features/<module>`.
5. Прогресс новичка хранится в `localStorage` (без аккаунта).

## Первый модуль

`success-plan-2026` - «План Успеха 2026».

Разделы как подстраницы: `/modules/success-plan-2026` (оглавление) и
`/modules/success-plan-2026/:sectionId`
(`overview`, `concepts`, `bonus-steps`, `examples`, `try`, `quiz`, `sources`).
Старые `#hash`-ссылки с оглавления редиректят на подстраницу.

## Публикация

Vite `base` по умолчанию `/school/` - имя папки/ожидаемого репозитория, не название бренда.
Переопределение: `VITE_BASE=/your-repo/ npm run build`.
Не меняйте `base` на `/` только из‑за ребрендинга в planB.
