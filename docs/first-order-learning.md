# Учебный модуль «Первый заказ»

Модуль находится по адресу `/learn/orders`; это навигационная страница со списком этапов. Старый адрес `/learn/products` перенаправляет на неё. Страница каждого этапа имеет собственный адрес, например `/learn/orders/products`. Карточка каталога обучения и этапы модуля описаны данными, чтобы материалы можно было менять без перестройки навигации.

## Этапы

Конфигурация находится в `src/data/learning/firstOrder.ts`. Каждый этап задаёт `id`, `path`, название, описание, тип содержимого, статус и числовой `order`. `path` используется в карточках и навигации между этапами; последний сегмент пути связывает URL с этапом. Стабильный URL не зависит от позиции этапа. Порядок задаётся только полем `order`.

- `ready` - содержимое показывается как готовый материал.
- `draft` - показывается заполненный в конфигурации текст-заглушка; когда материал готов, добавьте содержимое и измените статус.
- `hidden` - этап исключается из навигации и страницы.

Для нового этапа добавьте объект в `firstOrderStages`, укажите уникальные `id` и `order`, тип содержимого и статус. Общую оболочку, заголовок и отметку статуса отображает `LearningModuleStage`; содержимое собирается общим переключателем типа в `OrdersPage.tsx`.

## Содержимое и медиа

Обзор продукции берётся из `src/data/learning/products.ts`; инструкции, ситуации, официальный справочный адрес и чек-лист - из `src/data/learning/orders.ts`. Пошаговые последовательности используют общий `LearningStepSequence`. Для нового реального медиа заполните соответствующее поле конфигурации и укажите доступный текст `alt`/описание. Не добавляйте макеты интерфейса или скриншоты с личными данными.

Видео задаётся типом `LessonVideo` и отображается через существующий `LessonVideoPlayer`; плеер разрешает только поддерживаемые защищённые URL. Для статических изображений в конфигурации указывайте путь, собранный с `import.meta.env.BASE_URL`, например `${import.meta.env.BASE_URL}media/first-order/example.webp`, чтобы путь работал в корне и на GitHub Pages с `/school/`.

## Программа для новичков и предложения каталога

Условия программы для новичков и акции отдельного каталога - разные виды материалов. Проверенные каталоги и их предложения хранятся вместе в `src/data/learning/currentCatalogOffers.ts`: добавьте период каталога, его изображения (при наличии) и относящиеся к нему предложения. Даты, условия и ссылки заполняйте только после проверки официального источника. Компонент показывает каталог, даты и связанные предложения; без текущего периода отображает официальную страницу акций и пустое состояние. Не переносите предложения в отдельный несвязанный список.

## Данные и проверки

Отметки чек-листа хранятся только в состоянии открытой страницы. Учебный прогресс и `localStorage` модуль не меняет.

```bash
npm run typecheck
npm run test
npm run build
```
